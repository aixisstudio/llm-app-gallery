##  ️ Что это такое

Галерея ** полных, управляемых LLM-приложений** — не фрагменты, полные репозитории с архитектурой, которую можно изучать, клонировать и адаптировать. Самый быстрый способ изучить LLM-инжиниринг — это чтение реальных приложений.

##  ️ Архитектурные шаблоны, которые стоит украсть

1. **Streaming SSE** — каждый современный пользовательский интерфейс чата делает это одинаково
2. **Инструментальная петля** — `while tool_calls: execute → append → recall` — универсальный агентный скелет
3. **Структурный выход ** — режим схемы JSON > оперативное планирование, всегда
4. **Eval harness** — приложения, которые поставляются с папкой `evals/`; копируйте эту привычку
5. **Cost guardrails** — промежуточное ПО для бюджетирования токенов перед любым запуском prod
